미래제약 홈페이지 디자인 예제
==============================

구성
- home.html / home.css / home.js : 홈페이지 대문
- board-list.html / board-list.css / board-list.js : 게시판 목록
- board-view.html / board-view.css / board-view.js : 게시글 내용 보기
- board-write.html / board-write.css / board-write.js : 게시글 쓰기
- logo.svg : 미래제약 로고 이미지

실행 방법
1. ZIP 파일을 압축 해제합니다.
2. home.html 파일을 더블 클릭하거나 VS Code의 Live Server로 엽니다.
3. 헤더 메뉴의 '소식과 공지'에서 게시판 페이지를 이동할 수 있습니다.

참고
- HTML/CSS/JavaScript만 사용하는 정적 디자인 예제입니다.
- 검색, 분류 필터, 미리보기, 필수 입력 검사, 인쇄 기능은 브라우저에서 동작합니다.
- 게시글 저장, 실제 로그인, 파일 업로드, 페이지별 실제 데이터 조회는 서버와 데이터베이스가 연결되어야 합니다.
- 화면의 회사 정보와 수치는 디자인 시연을 위한 가상 예시입니다.
- CSS와 JavaScript에는 초보자가 이해하기 쉽도록 주석을 포함했습니다.
